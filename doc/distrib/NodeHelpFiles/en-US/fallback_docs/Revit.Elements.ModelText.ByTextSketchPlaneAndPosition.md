## In Depth
This node creates a Model Text element in a Revit family document.

In this example a text string is used to identify what will be written in the Revit family document and used as an input to the ModelText.ByTextSketchPlaneAndPosition node along with a sketch plane, x and y coordinate plane's, a text depth and model text type.  The output is a string of 3D text in a Revit family document.
