## In Depth
This node returns the location lines for walls (FinishFaceInterior, FinishFaceExterior, CoreCenterLine, CoreExterior, CoreInterior, WallCenterLine).

In this example CoreExterior is chosen from the Wall Location node and used to generate a wall with the offset of the wall starting from the CoreExterior face.
