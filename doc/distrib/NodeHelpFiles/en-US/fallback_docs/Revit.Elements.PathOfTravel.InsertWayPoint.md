## In Depth
This node inserts a waypoint into an existing Revit Path of Travel element. This forces the travel path to route through a specific location before continuing to its destination.

In this example, an existing waypoint element (must have more than a start and end point) has been selected and used as an input to the PathOfTravel.InsertWayPoint node along with a new point and index value for the new point.  The output is the same Path of Travel element with a new point inserted at the defined index.
