## In Depth
This node returns the transformation of a Revit Family Instance, with the option to remap that transformation between coordinate systems.

In this example a family instance is selected and two coordinate system are defined then used as input to the FamilyInstance.Transform node.  One of the coordinate systems is used as the original (fromCoordinateSystem) and the other is the target (contextCoordinateSystem).  The output is a repositioned family instance.
