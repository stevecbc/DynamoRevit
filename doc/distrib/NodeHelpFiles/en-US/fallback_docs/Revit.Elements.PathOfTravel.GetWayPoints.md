## In Depth
This node takes a PathOfTravel element as the input and outputs a list of points that represent the intermediate waypoints along that path.

In this example an existing way point element (must have more then a start and end point) has been selected and used as the input to PathOfTravel.GetWayPoints nodes.  The output is the points along that path.  This example also demonstrates a how to insert a new point then exposes the new point using the PathOfTravel.GetWayPoints node.
