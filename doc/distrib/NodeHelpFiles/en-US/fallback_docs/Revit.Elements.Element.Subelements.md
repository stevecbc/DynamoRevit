## In Depth
Element.Subelements returns the sub-elements that belong to a Revit element.  A sub-element is a smaller editable part of a larger Revit element (parts, faces, layers).

In this example all Rails are selected in the project and used as the input to Element.Subelements.  The output is a list of sub-elements if applicable.
