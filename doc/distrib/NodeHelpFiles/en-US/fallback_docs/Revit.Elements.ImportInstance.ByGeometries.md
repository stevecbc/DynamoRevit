## In Depth
This node takes Dynamo geometry objects and creates import instances in your Revit model, making the geometry visible in Revit.

In this example a sphere and a cuboid are created in Dynamo and used as the input to the ImportInstance.ByGeometries node.  The output creates a single piece of Revit geometry.
