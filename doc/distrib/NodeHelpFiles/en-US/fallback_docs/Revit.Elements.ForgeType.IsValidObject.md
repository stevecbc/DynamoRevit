## In Depth
This node is a validation tool that ensures your ForgeType references are still valid before they are used downstream.  

In this example the spec type length is selected and used as the input to ForgeType.IsValidObject node.  If the output is false, the data is not reliable.  If the output is true, the data is reliable.
For more information on ForgeType see below.
https://help.autodesk.com/view/RVT/2025/ENU/?guid=d9fcf276-9566-de83-2b0b-d89b65ccc8af
