## In Depth
This node creates a Revit Curtain System from one or more selected faces. 

In this example a curtain system is named and a mass face is selected then used as an input to the Revit.Elements.CurtainSystem.ByFace node.  The output is an a curtain system instance on the selected face.  To run this example you must first draw an in-place mass, then select a face using the Select Face node.
